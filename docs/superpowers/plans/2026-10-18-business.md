# NumerOM Business 250 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add private Excel employee import and evidence-based team planning to NumerOM mobile.

**Architecture:** A pure bounded import/report domain, an owner-scoped optimistic Mongo service/router, and focused React Native screens. Existing session, UI primitives and print delivery are reused; business data never feeds numerology hiring scores.

**Tech Stack:** FastAPI, Pydantic, Motor, openpyxl, Expo/React Native, TypeScript.

**Spec:** docs/superpowers/specs/2026-10-18-business-design.md

## Global Constraints
- Max 250 employees, 50 groups, 20 selected members per group; file 5 MiB.
- Identity and birth dates never influence employee suitability or team coverage.
- Pilot package explicitly 0 cost; no unconfigured paid offer or credit debit.
- Preserve the existing mixed checkout. Commit only isolated reviewed changes if safe; no whole-tree source commit.

## Review Focus
- Oversized/hostile Excel and formulas: reject before expensive parsing; no formula execution or silent cached values.
- 250/251 rows and duplicate employee IDs: reject with actionable row information, never partial commit.
- Cross-owner access and stale revision: owner predicates, atomic CAS, no partial changes.
- Account switches or late imports: no previous-company data displayed in a new session.
- Names/DOB/protected attributes: invariant report tests, unknown skills not fabricated.
