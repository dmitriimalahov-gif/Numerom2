# NumerOM в Telegram

Бот открывает полный интерфейс NumerOM как Telegram Mini App. Новая регистрация показывает 10 приветственных баллов сразу на экране входа, в шапке приложения, в сообщении меню и на кнопке меню чата. У существующего аккаунта сохраняется фактический баланс, история, покупки и прогресс.

Бот пользователя: **@numerom_bot**. Токен вводится локально, не в чат и не в репозиторий.

## Подключение владельцем

1. Создать бота через @BotFather → `/newbot` (пользователь уже сообщил @numerom_bot).
2. Открыть `artifacts/telegram-bot/Подключить Telegram бота.command`. Ввести токен в Terminal: символы не показываются. Скрипт проверяет `getMe` и показывает подтверждённый username.
3. Первый запуск запрашивает только токен. Telegram-контакт поддержки задаётся через `scripts/setup-telegram-bot.py --prices`. Цены настраиваются в приложении: **Админка → Настройки → Telegram Stars**. Укажите целые Stars для каждого пакета и полного разбора; **0 отключает новые покупки продукта**. Сохранение требует причины изменения. Курс евро в Stars не рассчитывается автоматически.
4. Скрипт проверит опубликованную страницу `/telegram/`, сохранит настройки с правами `0600`, подключит только `md.numerom.telegram-bot` и перечитает настройки API. Затем открыть бот → `/start`.
5. Проверить на своём аккаунте: регистрация/привязка → баланс в меню → открыть раздел → потратить баллы → `/balance`. Реальный вход и реальная оплата до подключения токена не проверены.

Без токена сервер возвращает 503 «Telegram-бот ещё не подключён»; публичный шлюз скрывает внутренние ошибки за 502. Обычный сайт продолжает работать.

## Функции

| Раздел | В Telegram |
|---|---|
| Регистрация и вход | Подписанные Telegram initData; новая регистрация или привязка через существующий пароль NumerOM |
| Баланс и история | Общая база проекта; баланс сразу после регистрации, команды `/balance` и `/menu` |
| Личные числа, совместимость, имя/адрес/телефон/автомобиль | Полные существующие экраны внутри Mini App |
| Ведическое время и самонаблюдение | Существующие расчёты и история |
| Обучение, уроки, практика, библиотека, аудиогид | Те же права доступа, прогресс и опубликованные озвучки |
| Полный разбор | Превью профиля, покупка, история, версии, PDF, готовые аудиоглавы и видео |
| Консультации, бизнес и команды | Существующие экраны и серверные проверки прав |
| Профиль | Общий профиль NumerOM; Telegram-регистрация не требует email |
| Администрирование | Только у существующих администраторов после привязки аккаунта |
| Покупки внутри Telegram | Telegram Stars; отдельная цена каждого продукта, подтверждение сервером |
| Поддержка | `/help`, `/paysupport`, `/terms` показывают контакт владельца |

Бот работает в личном чате. В группах он не показывает профиль, баланс или материалы. Полные интерактивные функции находятся в Mini App, а не в отдельных текстовых командах.

## Размещение и эксплуатация

Рабочая копия: `/Users/brandbox/Library/Application Support/NumerOM/runtime`.

- Секреты: `runtime/backend/private/runtime/telegram.env` (только локально, `0600`).
- Процесс: `runtime/scripts/run-telegram-bot.py`, один экземпляр через файловый lock.
- Служба: `~/Library/LaunchAgents/md.numerom.telegram-bot.plist`.
- Журнал: `runtime/backend/private/runtime/telegram-bot.log`, без токена и текстов сообщений.
- Конфиг: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_APP_URL`, `TELEGRAM_SUPPORT_USERNAME`, `TELEGRAM_STARS_PRICES`.
- Проверка без запуска: `scripts/setup-telegram-bot.py --check`.
- Запустить с сохранённым токеном без нового ввода: `scripts/setup-telegram-bot.py --start`.
- Сохранить токен без запуска: `scripts/setup-telegram-bot.py --configure-only`.

Бот использует long polling. Публичный webhook для входящих сообщений не создаётся. Обнаруженный существующий webhook не удаляется автоматически. Бот и API работают на компьютере владельца: при его отключении серверные функции недоступны.

Старые report-voice/report-video не включаются. Новая озвучка появляется через существующий механизм публикации VoiceStudio. Сборка включает проверенное новое «Слово автора»; удалённые старые записи не восстановлены.

## Оплата и восстановление

Цены из админки хранятся в `telegram_stars_config`, защищены проверкой текущих прав администратора, номером ревизии и журналом изменений. Каталог и новый счёт читают актуальную цену из базы без перезапуска бота. До первого сохранения используются прежние `TELEGRAM_STARS_PRICES`; после сохранения конфигурация из базы имеет приоритет. Уже созданный счёт сохраняет сумму до завершения или истечения срока, даже если продукт отключили. Меняется цена покупки в Stars, количество баллов в пакетах остаётся прежним.

Цены берутся только с сервера. JWT, имя пользователя, сумма из браузера и callback закрытия окна оплаты не подтверждают платёж. Зачисление выполняется только по `successful_payment`, полученному от Bot API, при совпадении владельца, заказа, валюты и суммы. Повторная доставка одной квитанции не начисляет баллы повторно. UUID незаконченной оплаты хранится в сессии браузера.

`telegram_payment_review` содержит отклонённые подтверждения и возвраты для проверки владельцем. Возвращённый платёж нельзя исполнить повторно; доступ к возвращённому полному разбору закрывается. Возврат уже использованных баллов/периода доступа требует ручного решения владельца, автоматического списания предположительной суммы нет. Отправка возврата через `refundStarPayment` в интерфейс администратора пока не добавлена.

Операции с неизвестным исходом не должны запускаться вручную заново с новым заказом без сверки квитанций. После аварии offset обновляется только после обработки; неподтверждённые записи повторно проходят идемпотентную обработку.

## Проверки перед запуском

Изолированные тесты используют отдельные MongoDB `numerom_test_telegram_*`, а не рабочие аккаунты. Проверяются подделка подписи/владельца, повторная регистрация, бонус один раз, привязка и отзыв входа, подделка суммы, повторная квитанция, возврат, полный разбор без списания баллов, восстановление потерянной ссылки и мобильный экран баланса.

Наличие сборки и зелёных тестов не означает, что бот зарегистрирован и доступен в Telegram: это подтверждается отдельно после ввода токена и реального `/start`.
