# Персональная схема NumerOM

Источник оформления — предоставленные P4W/SUW и KVADRATW. Экран расчёта повторяет расположение ячеек 1–4–7 / 2–5–8 / 3–6–9, личных чисел слева и снизу, сумм линий справа и снизу. В центре показано количество каждой цифры, а не фиксированные значения из учебного PNG. Все значения и пояснения приходят с сервера. Сохранённая дата определяет квадрат; изменение профиля не меняет этот результат.

Палитра: белый #FFFFFF, фон #F4F7FB, зелёная подложка #E8F4EE, выделение #CBE6DA, тёмный текст #003447, цвета девяти чисел из KVADRATW. Системный шрифт сохраняет читаемость в iOS/Android. Числа 26–30 px, подписи 11–13 px, трактовки 15/24 px. Центрирование только внутри схемы, пояснения выровнены слева.

На ширине 320 px пять колонок укладываются без горизонтальной прокрутки; минимальная высота нажатия 48 px. Нажатие на личное число, ячейку или сумму открывает окно с названием, значением, трактовкой и формулой. Нули отображаются явно, отсутствующие данные — прочерком. Мастер-числа не сводятся клиентом.

Под схемой — график планет с переключением линии/столбцов, осью 0–9 и днями недели. Выбор точки или доступной подписи показывает соответствующее серверное значение и пояснение. Это показатели одного расчёта, не прогноз на будущие даты. Никаких новых платных запросов при взаимодействии.

Порядок: серверный квадрат и чтение старых отчётов → интерактивная схема → графики → проверки нулей/мастер-чисел/сумм/отсутствующих данных и бесплатного просмотра → браузерная проверка 320/390 px → публикация по существующей ссылке. Исходные PNG остаются учебными материалами.
