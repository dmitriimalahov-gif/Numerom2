## Продолжение

Фоновые report-voice, report-analysis, report-video и report-delivery остаются под launchd. После завершения всех аудиоглав готовится MP4, затем отправляется письмо. Полная готовность двух оставшихся видео и всех оставшихся учебных записей на момент этой проверки не заявляется. Аудиопроверка Whisper не заменяет ручного прослушивания всех ударений.

Повторный аудит без изменения очереди:

```sh
backend/.service-venv/bin/python scripts/audit-project-narration.py --require-ready
```

Аудит автоматически выбирает runtime из защищённого service-location.json; данные runtime не копируются из устаревшего Desktop checkout.
