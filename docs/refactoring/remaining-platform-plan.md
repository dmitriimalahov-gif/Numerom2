# План завершения NumerOM

Продолжение утверждённого плана платформы. Срез на 18 октября 2026 после интеграции мобильных функций. Реализация, автоматические проверки, браузерная проверка и выпуск на устройства отмечаются отдельно.

## Реализовано и проверено в текущем этапе

- [x] Личные числа: сохранённые схемы, бесплатная история последних 100 результатов, подтверждение стоимости и повтор той же платной попытки без второго списания. Исправлена гонка между восстановлением истории и отправкой новой попытки.
- [x] Имя, адрес, автомобиль, совместимость пары и группы: серверная цена, проверка до списания, сохранённые результаты, графики и контекстные пояснения.
- [x] Авторские схемы: 29 оригинальных иллюстраций, отдельные разборы, поиск, переходы, увеличение и привязка соответствующих озвучек. Общая методика вынесена отдельно.
- [x] Комплексный личный отчёт: фрактал, четыре задачи, личные год/месяц/день, девятилетние циклы, Абракадабра и человечек имени. Формулы сопоставлены с исходным веб-отчётом. Буквенные схемы используют отдельные сохранённые имя и фамилию, без догадок для старых данных.
- [x] Ведическое время и маршруты на 1, 7, 30 и 90 последовательных дней: солнечные границы, 24 часа суточного расписания, периоды дня, графики, выбор даты, бесплатная история и безопасный платный POST. Неопределённое место, часовой пояс или неполные данные не приводят к списанию.
- [x] Опрос самонаблюдения: отдельный сценарий, сохранённые ответы и положение в опросе, разбор, диаграмма и история. После успешной оплаты повторный запуск требует явного действия.
- [x] Учебные сценарии: возобновление теста, черновики упражнений и дневника, вложения к ответам с ограничениями размера и проверкой доступа. Записи привязаны к аккаунту и учебному материалу.
- [x] Экспорт сохранённых личных расчётов, инструментов, совместимости, опросов и ведических маршрутов: HTML для печати/PDF и нативного share, без повторной оплаты. Транспорт проверен тестами; системные диалоги на физических устройствах ещё предстоит проверить.
- [x] Мобильное администрирование: обзор, пользователи/роли/доступы/баллы, уроки и материалы, ответы, консультации и настройки. Серверная проверка роли, защита конфликтов редактирования и доступ к файлам реализованы и покрыты тестами.
- [x] Ключи доступа WebAuthn и защищённое нативное хранение с биометрией. Токен удаляется из памяти синхронно при сворачивании; автоматическое восстановление не читает защищённый токен без явного подтверждения ОС.

Итоговый автоматический прогон этапа: **278 серверных тестов, 169 клиентских тестов, TypeScript и Expo export для web/iOS/Android — успешно**. Браузерная проверка основного агента подтвердила комплексный отчёт, треугольник имени и человечка на 320/390 px с бесплатной синтетической фикстурой. Для Кишинёва проверено настоящее суточное ведическое расписание из 24 часов. Эти проверки не заменяют физические устройства и полный публичный пилот.

## Правила реализации

Сохраняем существующие формулы и совместимость веб-клиента. Общую методику показываем один раз в разборе; выбранная ячейка содержит относящуюся к ней интерпретацию. Для платных действий баланс, результат и ключ повтора фиксируются атомарно. Проверки, меняющие данные, выполняем только в отдельной временной MongoDB. Успешный JavaScript export, native prebuild или установка Pods не означают установленное и проверенное на телефоне приложение.
