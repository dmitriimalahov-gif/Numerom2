# Личные числа в мобильном клиенте

Экран показывает последний сохранённый личный расчёт, дату рождения, серверное время сохранения и имя, использованное в отчёте. Семь значений доступны как выбираемые вкладки; смысл и конкретная расшифровка числа души открыты сразу. Формула и серверные шаги раскрываются отдельно. Планетарная сила отображает семь серверных показателей по шкале 0–9 и серверное объяснение формулы. Клиент не вычисляет нумерологические значения или тексты трактовок.

Отсутствующее число имени/мудрости обозначено прочерком и серверным примечанием; есть переход к профилю без изменения данных. Старые и неполные ответы показывают только полученные значения и честное сообщение об отсутствующих подробностях. Некорректная планетарная шкала не округляется и не подменяется.

## Запросы и оплата

- При открытии экрана автоматически выполняется только бесплатный `GET latestPersonalNumbers`. Повторное посещение смонтированной вкладки не повторяет запрос; отдельная кнопка позволяет повторить неудачную загрузку.
- Платный POST запускается только явным нажатием кнопки с загруженной целой неотрицательной ценой. Неизвестные цена/баланс, недостаток баллов и неподтверждённое обновление баланса блокируют запуск.
- Два быстрых нажатия разделяют один запрос. Поздний ответ загрузки истории не заменяет новый успешный расчёт.
- При неудаче повторного расчёта предыдущий результат и его дата остаются на экране. Изменённая дата формы подписана отдельно. После ошибки предлагается бесплатная проверка сохранённого результата.
- Обновление баланса выполняется отдельно. Его ошибка сохраняет полученный расчёт, показывает отдельную кнопку «Обновить только баланс» и не повторяет POST.
- Данные хранятся в состоянии экрана. Смена пользователя создаёт новое состояние; ответы и отложенные запросы старой сессии игнорируются. Нет общего кеша результатов или записи отчёта на диск.
- Сверху доступен переход к форме нового расчёта. После успешного расчёта экран возвращается к полученному результату; прокрутка не запускает платные запросы.

## Проверка

До изменения настоящий старый `numbers.tsx` был отрисован с серверной расшифровкой в данных: семь названий отображались, текст расшифровки отсутствовал (проверка завершилась ошибкой). Регрессионный тест отрисовывает настоящий новый компонент с лёгкими заменами нативных элементов и проверяет сразу видимые смысл/трактовку, семь доступных вкладок, семь полос, раскрываемые шаги и недоступное имя/мудрость.

`node --test test/personalReport.test.js` из `mobile`: 15 проверок проходят. Включены старые/некорректные ответы, нулевая планетарная сила, цена 0.5, актуальная дата сохранённого результата, поздний GET, повторное нажатие, неудачный POST, ошибка баланса, выход из аккаунта и отсутствие автоматического платного запроса. `npm run typecheck` проходит на Node 22.

Основной поток дополнительно проверил настоящий интерфейс на 390/320 px с отдельным MongoDB и вымышленным профилем Anna Li / 10.01.1982. Подтверждены значения 1, 1, 4, 11, 1, 22, 6; раскрытие шагов; семь полос планет; сохранение после перезагрузки; неизменность баланса при повторном чтении и переходе к форме. На 320 px нет горизонтального переполнения, ошибок в консоли не обнаружено. Это не проверка физического устройства. Готовый web export опубликован; версия и ограничения перечислены в `public-release.md`.
