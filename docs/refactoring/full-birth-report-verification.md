Публичный мобильный раздел: https://dmitriimalahov-gif.github.io/numerom-app/full-report/

Реализована отдельная разовая покупка по дате рождения: сохранённые расчёты, трактовки из базы знаний NumerOM, схемы, экспорт полного документа и персональные аудиоглавы. Баллы и подписки не участвуют. Имя, время, координаты и данные партнёра не выдумываются: соответствующие расчёты явно перечислены как требующие дополнительных данных.

## Ограничения приёмки

Stripe остаётся в TEST-режиме. Рабочие платежи не включались. Завершение даже тестового платежа через браузер отклонила автоматическая проверка безопасности: финальное действие должен выполнить пользователь. Поэтому полный браузерный сценарий «оплата → готовый отчёт» не подтверждён; серверные сценарии проверены тестами. Созданные для проверки временный пользователь и заказ удалены, открытый неоплаченный Checkout закрыт.

Озвучка подключена к локальному мужскому голосу Helper / Qwen3-TTS и выделенной службе `md.numerom.app.report-voice`, которая автоматически запускается и восстанавливает очередь. Первая пробная глава записана целиком: 84,08 секунды, расхождение распознанного текста по четырём фрагментам — 2,4%, 0%, 2,3% и 0%. После проверки улучшен исходный текст: общая тема совпавших чисел не повторяется, фрактал и позиции линий читаются по отдельным цифрам. Исправленная глава поставлена в очередь с новым хешем; существующие оплаченные снимки не изменялись. Высокая нагрузка на память/GPU может замедлять синтез; чужие процессы не останавливались. Проверка распознанного текста не заменяет прослушивание ударений и интонации. Интерфейс показывает подготовку аудио и открывает только проверенные готовые записи. Все 22 главы пробного отчёта ещё не записаны.
