# Время, маршруты и комплексный мобильный отчёт

Реализовано 18 октября 2026. Это описание исходников и проверок; публикация и проверки реальных устройств выполняются отдельно.

## Ведические расчёты

`/vedic-time` открывает расписание солнечного дня или персональный маршрут на 1, 7, 30 либо 90 последовательных дней. Интерфейс показывает реальные 24 планетарных часа для суточного результата, четыре периода дня, девять планетарных индексов выбранного дня и отдельный график выбранной планеты за весь период. Для суточного расчёта доступны круг 24 часов и шкала четырёх периодов. Время отображается в часовом поясе города без повторного преобразования в пояс телефона.

Новые authenticated endpoints: `GET /api/numerology/vedic/catalog`, `GET .../history`, `POST /api/numerology/vedic`. POST использует strict DTO и общий PaidCalculations с UUIDv4 попытки, подтверждённой стоимостью и атомарной записью результата/списания. Синхронный или async builder завершается до списания. Повтор использует сохранённый снимок, даже после изменения цены или профиля. Пять последних полных результатов доступны бесплатно; pending intent хранится отдельно для аккаунта. Legacy списывающие GET не используются мобильным экраном.

Арифметика `vedic_time_calculations` и `vedic_numerology` сохранена. Строго проверяются координаты, пояс, реальные солнечные границы каждого дня и следующего восхода. Неопределённый город, пояс, полярный день/ночь и неполный маршрут возвращают ошибку до оплаты. Старый резервный восход 06:00 и фиктивные hourly 50% не отображаются. Для геокодирования используется прежний Nominatim; его недоступность может мешать новым городам, повтор ранее оплаченного запроса не требует геокодирования.

## Дополнение личного отчёта

`packages/numerology-core/comprehensive.js` содержит арифметику, извлечённую из действующего `ComprehensiveReport.jsx`: фрактал, четыре задачи/возрастные границы, личный год/месяц/день и три задачи периода, тени/вершины/вызовы/переходы с последовательностью личных годов. UI раскрывает метод один раз для раздела, показывает формулы каждой позиции, сохраняет нулевые разности. Периоды относятся к UTC-дате сохранения результата, а не к дню повторного открытия.

Абракадабра и человечек используют только сохранённый `report.profile_parts` → `profileParts`. Полное имя не разбивается догадкой, существующий отчёт не пересчитывается с текущим профилем. A–Z проверяется до удаления разделителей; неподдерживаемые буквы не пропускаются молча. Треугольник требует 9 букв имени+фамилии; человечек — 4 буквы именно имени. Короткие и старые данные дают понятное объяснение отсутствия схемы. Оба алгоритма сопоставлены с исходным JSX на нескольких именах, в том числе составных.

Озвучки: пять `vedic-*`, шесть `comprehensive-*`; исходные тексты в соответствующих packages/*-knowledge/ru.json, генерация и аудиопроверка отдельной очередью.

## Экспорт

Из сохранённых assessment и vedic результатов формируется самостоятельный HTML через общий безопасный PDF/print/share transport. Личный PDF включает все шесть дополнений. Новых API запросов или списаний экспорт не делает. Все текстовые значения экранируются; документ запрещает сеть и скрипты через CSP.

## Проверки

- Ведический domain: 4 теста, реальные 1/7/30/90 дней, строгие входы, недоступные города/солнечные границы/неполные показатели, совпадение суточной формулы.
- Изолированная MongoDB 27039: 3 теста ведического сервиса плюс 9 регрессионных тестов синхронных personal/tools. Конкурентные повторы создают одно списание; replay не пересчитывает результат; auth и GET не списывают баллы.
- Mobile: 4 теста контракта/графика/восстановления попытки, 4 теста комплексных формул и экспорта, существующие personal/export проверки.
- `npm run typecheck` пройден.
- В браузере новый authenticated комплексный UI в этой подзадаче не подтверждён: автоматическая проверка отклонила вход тестовым аккаунтом; общий браузерный проход выполняет основной агент. Ранее схемы и личный PDF проверены на 320/390px (см. mobile-schemes-and-export.md).

Обновление схем и векторного экспорта, включая DST: см. `mobile-schematic-reports.md`.
