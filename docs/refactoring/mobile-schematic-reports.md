# Персональные схемы на мобильном экране и в отчётах

18 октября 2026. Изменения используют сохранённые результаты; открытие схем, смена дня и экспорт не запускают расчёт и не списывают баллы.

## Как открыть

- «Личные числа» → «Все схемы: имя, задачи и личные периоды» → «Абракадабра имени» или «Человечек имени».
- Меню ☰ → «Время и планетарный маршрут». Сохранённый маршрут открывается из истории.
- «Сохранить или напечатать PDF» включает все схемы результата, независимо от выбранной вкладки или планеты.

## Имя

Общая модель `nameSchemeVisuals` обслуживает React Native SVG и самостоятельный HTML для PDF. Абракадабра сохраняет авторский сдвиг рядов вправо, 45 ячеек и 72 связи. У ячейки доступны исходная буква либо два слагаемых с сокращением суммы, трактовка и существующая озвучка цифры. График показывает первые девять букв имени и фамилии.

Человек имени содержит семь исходных позиций со связями. Рядом дано распределение чисел букв только имени. На узком экране схема целиком помещается в карточку; «Крупнее» включает горизонтальный просмотр. PDF содержит векторные схемы, графики и пояснения каждой позиции человека.

Схемы используют отдельные имя/фамилию из снимка расчёта. Старые отчёты без этих полей, неподдерживаемый алфавит и слишком короткие имена показывают объяснение; данные не дополняются догадками.

## Время

Для маршрутов на 1/7/30/90 дней показывается график выбранной из девяти планет с точными сохранёнными индексами. День можно выбрать касанием графика или стрелками. Для одной даты рисуется одна точка. При отсутствующих данных линия прерывается. На узком графике количество подписей дат уменьшено, чтобы они не накладывались.

Четыре периода расположены на общей шкале от восхода до заката. Выбор полосы открывает её время и пояснение. Суточные расчёты с 24 сохранёнными часами показывают круг: сектор соответствует продолжительности интервала, номер позволяет открыть конкретную планету и время, ночные часы явно отмечают переход даты.

Дневные и ночные часы теперь делятся по фактическому времени UTC, затем переводятся в часовой пояс города с явным смещением. Это устраняет расхождение на час при переходе DST в pytz/ZoneInfo. Новые круги используют реальную продолжительность, старые записи без смещения — сохранённые местные часы. Архивные результаты не пересчитываются автоматически.

В PDF включены все девять графиков периода, шкала каждого дня, круг часов при наличии и точные числовые значения. SVG не обращаются к внешним ресурсам; весь пользовательский текст экранируется. Дата сохранения без смещения трактуется как UTC, как и в других отчётах.

## Проверка и выпуск

Артефакты проверок, синтетические отчёты и скриншоты находятся в `artifacts/mobile-schematic-reports-20261018/`. Тестовый API и MongoDB изолированы от настоящих аккаунтов; примеры Anna Petrova вымышленные. Публичный выпуск содержит только проверенные статические файлы. Сборка iOS Simulator находится отдельно в `artifacts/mobile-native/schematics-20261018/`; это не подписанный IPA и не проверка на физическом телефоне.

Итог: 265 клиентских тестов и 12 серверных тестов прошли, проверка TypeScript и чистая веб-сборка завершились успешно. В браузере проверены схемы и нажатия на ширине 320 px, выбор даты на графике, выбор планетарного часа и открытие печатного отчёта. Сохранение окончательного PDF средствами ОС и нативный интерфейс на телефоне не проверялись.

Выпуск: https://dmitriimalahov-gif.github.io/numerom-app/ — статический коммит `7f7385406f2e006154a561c6f2845ba405aaefcc`, успешный GitHub Pages workflow `39114696243`.
