# Мобильные авторские схемы и экспорт

18 октября 2026.

## Авторские схемы

`Gallery` связывает 29 оригинальных PNG с `packages/scheme-knowledge/ru.json` по ID, а не по позиции массива. Каталог проверяется на полное покрытие, дубли и отдельные ID озвучки. Названия и учебные объяснения берутся из каталога: например, HSU теперь показывается как Венера, личные числа получают осмысленные заголовки.

В разделе есть поиск по заголовкам и полному тексту, фильтры, разбор «Смысл / Как читать / Внимание», переход по отфильтрованным примерам и увеличение изображения 100–300% с прокруткой по двум осям. Оригинальные числа/цвета не меняются. Общее объяснение метода и его отличий от учебных источников раскрывается один раз в галерее. Истории девяти чисел сохранены отдельным раскрываемым блоком.

Вход не нужен для локального текста `/guide`; закрытая озвучка использует существующий `/narration/project` и точный `entry.narration.id`. API вызывается только в авторизованном контексте. Смена схемы или закрытие модального окна размонтирует предыдущий аудиоплеер. Анимация появления мягкая, не циклическая, отключается при reduce-motion и в фоне.

## Экспорт

Кнопка в `PersonalReport` формирует документ из уже открытого `PersonalResultView`. Экспорт не обращается к API расчёта или оплаты. В документ входят реальные личные числа, квадрат и суммы линий, формулы, планетарный векторный график, доступные серверные расшифровки и истории цифр. Недостающие значения остаются отсутствующими, нули сохраняются. Все пользовательские/серверные строки экранируются; документ самодостаточен и ограничен CSP без сети и скриптов.

На web печатается только документ в отдельном sandbox iframe: браузер предлагает печать/сохранение PDF. На iOS/Android `expo-print` создаёт PDF локально, `expo-sharing` открывает системное меню; временный файл удаляется после возвращения меню. Если sharing недоступен, открывается нативная печать. Отмена системного диалога не является доказательством сохранения файла.

- Существующие 18 тестов персонального отчёта прошли после интеграции.
- TypeScript прошёл.
- Expo web export собран для локальной проверки.
- Browser QA: открытие/переключение схем, «Как читать», поиск Венеры, увеличение/уменьшение/возврат, исходная картинка, 320/390px без горизонтального переполнения. Обнаружена и исправлена особенность RN Web: intrinsic PNG height перекрывала aspectRatio; теперь высота вычисляется от измеренной ширины.
- HTML отчёта проверен в браузере на 320/390px; схема и график присутствуют, переполнения нет. Артефакты: `artifacts/mobile-schemes-20261018/`.
