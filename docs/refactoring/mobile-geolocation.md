## Поведение

- В планетарном маршруте: «Определить мой город» запрашивает разрешение ОС/браузера и заполняет город со страной. «Транслировать геолокацию» обновляет выбранное место при перемещении, пока открыт экран. Можно остановить кнопкой. Ручной ввод остаётся доступен.
- В профиле: только разовое определение. Сохраняется название города после обычного нажатия «Сохранить изменения»; координаты профилю не передаются.
- Выход с экрана, фон, скрытая вкладка, ручная правка, блокировка формы и смена аккаунта отменяют наблюдение. iOS inactive во время системного разрешения само по себе не считается уходом в фон.
- AbortSignal отменяет и разовый поиск, и live-подписку. Позднее разрешение не запускает наблюдение; поздний handle удаляется. Старый ответ определения города не заменяет новую позицию.
- Определение города бесплатно, платный расчёт запускается только кнопкой пользователя. Его координаты фиксируются в запросе/отчёте; повтор использует прежние координаты и UUID. Сохранённый отчёт не меняется при перемещении.

## Данные и расчёт

Аутентифицированный POST `/api/numerology/vedic/location` принимает только конечные числовые latitude/longitude допустимого диапазона и возвращает город, страну, исходные координаты и серверный часовой пояс. Часовой пояс клиента не принимается. Ответ no-store, lookup не пишет в базу и не списывает баллы.

Nominatim получает округлённые до 0,001 градуса координаты для названия населённого пункта, без улицы/дома. Объём ответа/таймаут ограничены, TLS проверяется. Одна upstream-операция одновременно, не чаще одного раза в секунду на процесс; RAM cache 128 ключей, TTL 10 минут. Мобильный live reverse lookup выполняется после перемещения на 1 км, не чаще одного раза в минуту. Координаты не печатаются в журнал запросов; непрерывная история перемещений не ведётся. Место подтверждённого расчёта входит в приватную историю отчётов и в хранилище незавершённой попытки.

Все пять ведических периодов используют координаты через изолированный ContextVar с finally-reset, не меняя общий кэш города. Старые запросы только с названием города сохраняют исходный fingerprint и возможность повтора.

## Проверка

- 200 клиентских тестов прошли; 38 серверных тестов, включая настоящую изолированную MongoDB, прошли без пропусков.
- Независимое ревью подтвердило исправления позднего ответа и отмены разового OS watch.
- TypeScript, web export, iOS/Android JS export прошли.
- Expo introspection: только разрешение использования местоположения при открытом приложении; фоновые location/motion/foreground-service разрешения отключены.
- Реальный upstream-запрос с общедоступными тестовыми координатами центра Кишинёва вернул «Кишинэу, Молдова», Europe/Chisinau. Геолокация пользователя не получалась.
- Браузер: синтетический аккаунт на изолированной базе, обе формы города, ручной ввод; ширина 390 px без горизонтального переполнения, console errors отсутствуют. Реальное разрешение GPS не выдавалось.
- Backend и gateway перезапущены, публичные защищённые маршруты отвечают 401 без входа. Рабочие MongoDB, туннель и основной frontend сохранены.

Физические iPhone/Android и системные разрешения GPS не проверены. Установочные native-сборки после добавления expo-location в этом этапе не создавались: прежний Simulator ZIP предшествует геолокации. Для него требуется новая native-сборка; JS export не заменяет её.
