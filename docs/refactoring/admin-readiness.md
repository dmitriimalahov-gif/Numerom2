# Готовность веб-админпанели NumerOM

Дата проверки: 16 октября 2026. Вход: `/dashboard/admin`; старая ссылка `admin-v2` перенаправляет в `/dashboard/admin/learning`.

Это проверка исходного кода, React-компонентов с подменённым транспортом и сборки. Реальная база, письма, покупки, платные операции и браузерная сессия пользователя не использовались.

## Исправленная совместимость ученического теста

Веб-клиент отправляет только `lesson_id`, `quiz_id`, `answers`, `submission_id` (UUID). Неизменённая попытка при повторе сохраняет идентификатор; итоговые `score` и `passed` берутся с сервера. При ошибке нет локального «успеха». Результаты старого урока не заменяют открытый урок.

Редактор синхронизирует правильный ответ при переименовании варианта; новые вопросы получают свободные идентификаторы после удаления предыдущих. Порог 0 сохраняется.

## Проверки

Из `frontend`:

```sh
CI=true ./node_modules/.bin/craco test --watch=false --runInBand src/features/admin/__tests__ src/features/learning/__tests__/quiz-submission.test.jsx
GENERATE_SOURCEMAP=false ./node_modules/.bin/craco build
```

- 21 тест в 4 наборах: права доступа до запросов, подтверждение/конфликт кредитов, поиск без устаревшего ответа, роли, реальные пути всех пяти разделов, консультации и защищённый PDF, настройки/повтор/нулевые значения, сохранение и загрузка урока, вложения всех разделов, целостность вопросов, серверный результат и повтор ученического теста.
- Production-сборка прошла. Предупреждения относятся к возрасту справочников Browserslist/baseline-browser-mapping.
- Тесты используют настоящие UI-компоненты и API-клиент с подменой `fetch`; в auth-тестах подменена только конфигурация axios.

## Условия запуска и оставшиеся ограничения

1. Сервер должен включать новый `GET /api/admin/consultations/files/{file_id}` из `backend/routers/admin_media.py`. Ранее UI обращался к отсутствующим `/consultations/video` и `/consultations/pdf`; эти пути заменены в действующем разделе консультаций.
2. Восстановление пароля по почте зависит от настройки сервера. Карточка обзора показывает конфигурацию; доставка писем этой проверкой не подтверждалась. Пароли и токены восстановления в административный UI не выводятся.
3. Нужна отдельная приёмка на тестовых данных в запущенном приложении: вход администратора/ученика, обновление страницы на каждом маршруте, реальные видео/PDF и узкий экран. Mock-тесты и сборка не доказывают состояние опубликованной среды.
4. Большой видеофайл сначала загружается целиком для защищённого blob-просмотра. Потоковое воспроизведение больших файлов — отдельное улучшение.
5. Сервер не возвращает сохранённые имена вложений консультации после перечитывания записи; UI показывает наличие по `file_id` и понятную подпись. Просмотр от имени ученика и оплаты вне этой проверки.

Старые внутренние ветки `AdminPanel` (materials/lessons/system), не подключённые к пяти разделам workspace, не объявляются прошедшими полный аудит. Проверка доступов API и изменений backend ведётся отдельно; этот отчёт фиксирует фронтенд.
