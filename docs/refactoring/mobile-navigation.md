# Мобильная навигация и завершение сценариев — 18.10.2026

## Выполнено

- Все разделы доступны из постоянного меню ☰ сверху слева. Для вошедшего пользователя — 13 пунктов в группах: главная, расчёты, обучение, услуги и аккаунт. Администратор дополнительно видит управление платформой.
- Нижняя панель скрыта; основные экраны сохраняют черновики при переходах. Вложенные страницы получили кнопку возврата, включая запасной переход при прямой ссылке.
- Меню отмечает текущий раздел, закрывается после выбора, при смене аккаунта и сворачивании. Учтены Escape, фокус клавиатуры, экранный диктор, системная кнопка назад и сокращение анимаций.
- Восстановление пароля показывает адрес запроса, позволяет его исправить и повторить отправку через 60 секунд. Параллельные нажатия не создают дублирующие запросы.
- Запрос доступа к закрытому учебному файлу или консультации отменяется при уходе с экрана, сворачивании и смене сессии. Запоздавший ответ не открывает файл поверх другого экрана или аккаунта.

## Проверки

- 218 клиентских тестов: успешно; TypeScript и Expo web export: успешно. Отдельные 10 тестов навигации включают реальный React Native Web Modal в JSDOM.
- Проверен браузер на 320 и 390 px: все 13 пользовательских разделов и администрирование доступны, горизонтального переполнения нет. Проверены переходы гостя, Escape/возврат фокуса и сохранение черновика даты рождения после перехода в профиль и обратно.
- Восстановление проверено через HTTP на отдельной временной MongoDB с фиктивным почтовым адаптером: подтверждение запроса, адрес, таймер, исправление адреса и новый запрос. Настоящие письма не отправлялись; доставка SMTP этим не подтверждается.
- Ошибок console.error в просмотренных тестовых сценариях нет. На публичной версии проверены раскрытие меню и гостевой доступ к схемам.
- Снимки интерфейса: `artifacts/mobile-navigation-20261018/menu-390.png` и `menu-320.png`. Они сделаны с синтетическим тестовым аккаунтом.
