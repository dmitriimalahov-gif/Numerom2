# Полный разбор по дате рождения — 6,66 €

Разовая покупка одного сохранённого отчёта для указанной даты. Баллы не используются. Повторное чтение, аудио и PDF входят в покупку. Отдельные даты — отдельные заказы; дата расчёта фиксируется при создании заказа.

1. Свести действующие формулы: личные числа, квадрат и восемь линий, планетарный график, фрактал, задачи, периоды, персональные числа года/месяца/дня. Подтвердить совпадение с существующими расчётами. Не выдумывать имя, время рождения, координаты или партнёра.
2. Сохранить персональные трактовки из базы знаний, схематические данные и тексты аудиоглав одним неизменным документом.
3. Отдельный Stripe Checkout: 666 евроцентов, серверная цена, UUID попытки, сверка подписанного уведомления и состояния Stripe, доступ только владельцу оплаченного заказа. Тестовый режим отделён от рабочего.
4. Страница услуги на сайте и мобильном клиенте: состав, дата, стоимость, возврат после оплаты, история, весь текст, графики, озвучка по главам и PDF.
5. Локальный мужской голос Helper/Qwen: автоматическая очередь персональных глав, защищённые ссылки, автозапуск выделенного обработчика и восстановление незавершённых записей.
6. Проверить формулы, изоляцию пользователей, повторные/поддельные оплаты, возврат и восстановление, экспорт, сборки. Опубликовать мобильный интерфейс; отдельно зафиксировать действительный режим Stripe и готовность аудио.

Дизайн: сохраняем NumerOM — фон #F4F7FB, белый #FFFFFF, глубокий синий #183B62, текст #20364E, акцент #356FA5, спокойный зелёный #28705E. Существующая типографика приложения; крупный заголовок, пояснение состава, одно поле даты и явная кнопка разовой оплаты. После покупки сначала вывод, затем оглавление/аудио и раскрываемые разделы. Графики показывают реальные величины расчёта. Вся страница работает на узком экране; PDF содержит полный текст независимо от раскрытия разделов.

## Границы готовности

Рабочая оплата не включается автоматически при тестировании. Полный отчёт по дате не подменяет расчёты, которым нужны другие исходные данные. Текст может быть готов раньше аудио; интерфейс показывает фактический статус записи. PDF формируется из сохранённого результата, а не пересчитывается на текущую дату.
