## Что доступно

Светлый мобильный интерфейс, векторный логотип и 29 исходных учебных PNG; вход, регистрация, профиль, персональные числа и стоимость до расчёта, восстановление пароля, история баллов, уроки, отметка чтения, упражнения, серверная проверка тестов и сохранённый прогресс. Пароль владельца не изменяли; появление письма во входящих и завершение сброса владельцем не подтверждены. Сервер хранит только хеш токена; секретная ссылка не записывается в журналы доступа.

## Текущая архитектура

Браузерная версия, runtime-config.json и API доступны только через `https://1.numer.om`. GitHub Pages отключён и не является адресом входа. GitHub Actions используется только для проверенной сборки и атомарной доставки статики на сервер. Backend, MongoDB и приватные медиа работают в авторитетном Mac runtime через ограниченный доменный мост.

Шлюз слушает loopback `127.0.0.1:8004`, backend `127.0.0.1:8000`; внешний домен направлен только на шлюз. Его политика описана в `public-api-review.md`. Регистрация и защищённые данные требуют серверной авторизации; нерассмотренные маршруты наружу не опубликованы.
