# Локальный запуск NumerOM на этом Mac

Дважды нажмите `Запустить NumerOM.command` в корне проекта. Затем откройте http://127.0.0.1:5128/.

Из терминала в корне:

```sh
backend/.venv/bin/python scripts/start-local.py
```

Команда использует существующий Python venv, Node 22+ из nvm, зависимости frontend и закрытый `backend/.env`. Сначала проверяет подключение MongoDB. Если MongoDB недоступна, запустите существующий контейнер базы; команда не создаёт другую базу и не переустанавливает проект. API слушает 127.0.0.1:8000, frontend — порт 5128. Frontend запускается с актуальным CRACO-конфигом проекта, включая общий пакет `@numerom/api-client`.

Запущенные сервисы сохраняются после завершения команды; повторный запуск не создаёт дубликаты. Ошибка запуска возвращает ненулевой код и путь к журналу `backend/private/runtime/`. Файл `.env` и журналы не публикуются. Команда не останавливает процессы и не устанавливает системный автозапуск.

Публичная мобильная версия дополнительно требует шлюз 127.0.0.1:8004 и действующий Cloudflare Tunnel. Запуск локального сайта не восстанавливает истёкший публичный адрес. При смене адреса обновляются `PUBLIC_API_URL`, Stripe webhook и мобильная сборка; backend перезапускается. Текущий адрес и проверенная публикация записаны в `public-release.md`.

18.10.2026: воспроизведены отказ подключения к 5128 и DNS-ошибка прежнего туннеля. После восстановления локальная страница возвращает 200 и открывается в браузере, мобильная форма получает ответ API. Проверены повторный запуск команды, синтаксис Python/zsh, TypeScript и web export через скрипт публикации. Холодный запуск всей машины этой проверкой не подтверждён.
