# Завершение мобильных сценариев — 18 октября 2026

Поручение: проверить оставшееся и выполнить всё доступное без дополнительных вопросов. Сохраняем общий аккаунт, реальные расчёты, спокойный дизайн и смысловую озвучку каждого нового расчёта.

1. Продолжение теста и автосохранение заметок дневника; сохранение неопределённой отправки, конфликт версий и смена аккаунта.
2. Вложения PDF/PNG/JPEG к учебному ответу: ограничение размера, приватное хранение, права владельца/проверяющего, доступ с телефона.
3. Экспорт уже оплаченного отчёта с цифрами, схемами и интерпретациями; без повторного расчёта и списания.
4. Проверка администрирования и пользовательского пути на изолированной базе; устранение подтверждённых разрывов.
5. Сборки и публикация; проверка публичного кода и API. Отдельно фиксируем оставшиеся внешние условия магазинов, платежей LIVE и постоянного размещения.

Существующий большой рабочий diff сохраняется. Изменяющие проверки используют временную MongoDB в tmpfs; реальные аккаунты и рабочая база не используются. Публичный репозиторий содержит только проверенную статическую сборку.


## Проверенный результат

- В мобильной версии доступны авторские схемы, дополнительные личные расчёты, ведическое расписание/маршруты, опрос самонаблюдения, администрирование и PDF сохранённых отчётов.
- Обучение сохраняет положение теста и дневниковые черновики; учебные ответы поддерживают приватные вложения. История и повторы оплаченных расчётов не вызывают повторного списания.
- Добавлены WebAuthn-ключи доступа и защищённое нативное хранение с биометрией. Независимое ревью воспроизвело и помогло исправить две гонки: быстрый возврат из фона и одновременное восстановление/отправка расчёта.
- 278 серверных тестов на изолированной MongoDB, 169 клиентских, TypeScript и Expo export web/iOS/Android прошли. Полный лог и контрольный JSON находятся в artifacts/mobile-completion-20261018.
- 232 актуальные записи готовы, включая 51 новую. Проверены исходные хеши, файлы и автоматическое совпадение слов; полное ручное прослушивание ударений не заявляется.
- Выпуск ebbec849e3a95fd14d90af391b49d9e438133c0b, GitHub Pages workflow 39107541300 success. HTML/JS совпали побайтово; все 18 постоянных маршрутов дают HTTP 200. Защищённые новые API без сеанса возвращают 401.
- Браузер: 320/390 px, авторские схемы и ячейки, полный отчёт/именные схемы, сохранение учебного теста и дневника, реальное суточное ведическое расписание Кишинёва, административное редактирование урока. Загрузка PDF через системный выбор файла не подтверждена: вызов не завершился и был прерван; серверные проверки прошли.

## Ограничения выпуска

Stripe остаётся TEST; постоянный backend/домен, LIVE, возвраты и споры, аккаунты магазинов и физические устройства требуют отдельного завершения. Android JDK/SDK отсутствуют. Release arm64 для iOS Simulator успешно собран и установлен. Архив NumerOM-ios-simulator-arm64.zip (19 738 391 байт) проверен на целостность; SHA-256: 22321fffdc7ab24f4e343af9fcadc567d2b6d47318a6b824b5cc1a3eed817a33. Экран первого запуска не проверен: инструмент управления симулятором не вернул состояние за 332,2 секунды. Биометрия на физическом устройстве не проверена. Это архив для Simulator, не IPA/APK и не выпуск в магазины. Подробности: mobile-native-check.md и artifacts/mobile-native/verification.json.

Нативная иконка: пустой ресурс Expo заменён рендером исходного векторного NumerOM; iOS PNG не содержит альфа-канала, Android использует прозрачный foreground с безопасными отступами. TypeScript и повторный экспорт трёх платформ после этой правки прошли.
