# Восстановление, управление и живой логотип — 15.10.2026

## Реализовано

- Публичные `/forgot-password` и `/reset-password`, ссылка «Забыли пароль?» на сайте и в Expo-приложении. Новый пароль действует для обоих клиентов.
- Случайный одноразовый токен на 30 минут, в базе только SHA-256; токен передаётся в URL fragment и сразу убирается из адресной строки формы. На этих страницах отключён прежний PostHog, выставлен referrer policy. Смена пароля увеличивает версию авторизации, отзывает прежние сессии; параллельный запрос не восстанавливает отменённый токен.
- Одинаковые публичные ответы для известных/неизвестных email, ограничения частоты в Mongo, срок жизни служебных записей. SMTP использует TLS. При отсутствующих настройках форма сообщает о недоступности; реальные письма во время проверки не отправлялись.
- Общая админпанель `/dashboard/admin`: обзор, пользователи/доступы/кредиты, уроки, консультации, настройки. Старая ссылка `admin-v2` ведёт в раздел уроков. Поиск, страницы списка, роли и блокировка с причиной, подтверждение баланса, проверка устаревших данных, последние 100 административных событий.
- Баланс, событие аудита и запись очереди истории сохраняются одним обновлением пользователя. История доставляется повторяемым upsert по уникальному ID; сбой не теряет начисление и не дублирует запись. Пользовательская история не раскрывает внутреннюю причину администратора.
- Права проверяются по текущему аккаунту в базе; заблокированному аккаунту отказано. Удалён фиктивный `login-v2`, старое изменение баланса использует общую проверку. Защищены административные маршруты видео Bunny; при отказе внешняя операция не начинается.
- Первичный администратор создаётся только с явными настройками; запуск сервера не меняет пароль и роль существующего аккаунта. Шаблонный ключ подписи в локальном `.env` заменён случайным, прежние локальные сессии требуют повторного входа.
- Векторный логотип: короткое пробуждение, объёмный наклон, три планеты на орбитах, три палитры при повторе, остановка в фоне и статичная версия при reduced motion. Оригинальный SVG сохранён. См. `living-logo.md`.

- Браузер: изолированный аккаунт администратора, обзор, карточка пользователя, подтверждение 12→17 и сохранённая история; живой логотип в мобильном web preview, экран восстановления. Секреты/реальные пользовательские записи не использованы для UI-тестов.
- Обновлённый локальный backend запущен на 8000; новые маршруты присутствуют, anonymous admin/Bunny дают 401, восстановление при отключённой почте — 503. Рабочая база не использовалась для тестовых начислений.

## Подключение Gmail

Локальный отправитель установлен по запросу владельца: `dmitrii.malahov@gmail.com`. Сервер: `smtp.gmail.com`, порт 587, STARTTLS. Владелец ввёл пароль через помощник; **Gmail SMTP login подтвердил успешную авторизацию (235)**. Письма во время этой проверки не отправлялись. Обнаружено пустое системное хранилище CA в Python на Mac; добавлен fallback на доверенный certifi bundle, проверки сертификата и имени сервера остаются включёнными.

1. Открыть <https://myaccount.google.com/apppasswords> в своём Google-аккаунте. При необходимости включить двухэтапную проверку. Создать пароль приложения **NumerOM**; [официальная инструкция Google](https://support.google.com/mail/answer/185833?hl=ru).
2. Запустить `scripts/Подключить Gmail.command` двойным щелчком. Вставить пароль приложения в скрытый ввод. Он сохраняется в игнорируемом `backend/.env` с правами 0600, не выводится в чат/журнал и не передаётся третьим сторонам этим помощником.
3. Перезапустить backend NumerOM. Сам помощник не перезапускает сервер и не отправляет письма.

Настройки: `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURITY` (`starttls`/`ssl`), `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`, `PASSWORD_RESET_URL`. Локально последний адрес — `http://127.0.0.1:5128/reset-password`: он работает на этом Mac. До публичного выпуска заменить его настоящим HTTPS-адресом сайта; localhost-ссылка не подходит для телефона или другого компьютера. Для сервера также обязателен сильный `JWT_SECRET_KEY`/`SECRET_KEY`.
