## Изменения

- Независимый пакет `packages/api-client`: HTTP-контракты, настройка URL без скрытой подмены сервера, ошибки/таймаут/отмена, даты, сессия с безопасной обработкой запоздалых ответов и сетевых сбоев.
- Сайт использует общий resolver и клиент профиля. Дополнительно исправлена старая гонка при переключении аккаунтов: ответ предыдущего аккаунта не изменяет новую сессию.
- В действующем backend выделены `routers/accounts.py`, `services/accounts.py`, `domain/name_numbers.py`. Login и profile-v2 GET/PATCH подключены один раз, пути сохранены. PATCH валидирует дату и разрешённые поля; ответ не раскрывает хеш пароля. Логи фрагментов пароля/токена убраны из затронутых обработчиков. Добавлен read-only endpoint стоимости расчёта.
- Создан `mobile`: Expo Router, TypeScript, native SecureStore, светлый интерфейс, общие аккаунты/API; рабочие вход/регистрация/кабинет/персональные числа/текст уроков/профиль/PNG.
- Логотип NUMEROM SRL (entity 1) восстановлен в SVG по JPG из JARVIS: прозрачный фон, надписи в контурах, светлая/тёмная версии. Единый мастер `packages/brand/numerom-logo.svg`; скрипт синхронизации проверяет копии для сайта, favicon/PWA и native react-native-svg. Растр не встраивается в SVG, белой подложки/обрезки/внешних шрифтов нет. Исходный JPG сохранён отдельно для сверки. 29 PNG учебных иллюстраций сохранены без изменения.
- Docker context сайта учитывает общий пакет, основной nginx поддерживает same-origin `/api/` и `/uploads/`. Существующие работающие контейнеры не заменялись.

- TypeScript strict: без ошибок. Expo: совместимые версии; doctor 21/21.

## Ограничения и продолжение

Локальный frontend на 5128 перезапущен для новой конфигурации общего пакета и успешно компилируется. Действующий backend не перезапускался. Для нового `/api/numerology/costs` требуется запуск обновлённого сервера. Для web preview на 5130 нужен CORS origin; native CORS не использует. iOS/Android device QA, подписанные IPA/APK и публикация не выполнены; CocoaPods/Java отсутствуют. При тестировании использован Node 22.22.2; отдельные shell-процессы выбирали старый Node, поэтому итоговые сборки запускаются с явным PATH.

npm audit: 28 advisories в зависимостях (18 high, 10 moderate); не применён несовместимый major downgrade. Обязательная проверка перед выпуском. Старые глобальные настройки секретов, CORS, конкурентное списание кредитов, дубли learning routes и legacy-монолиты ещё входят в дальнейшие этапы; этот этап не является полным аудитом безопасности.

Следующие модули: атомарное списание/история и остальные расчёты; обучение с доступами, упражнениями и native media; консультации/отчёты/платежи; администрирование и разбиение крупных web-компонентов; CI, device QA и выпуск. `backend_clean`, архивы и пользовательские материалы не переносились и не удалялись. Изменения оставлены незакоммиченными вместе с существующим редизайном; публикации нет.
