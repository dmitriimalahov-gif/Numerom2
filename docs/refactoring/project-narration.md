# Озвучка NumerOM

Один синтетический мужской голос Helper № 4. Запись выполняется локально
Qwen3-TTS 1.7B Base bf16; Whisper large-v3-turbo сверяет произнесённые слова.
Облачные сервисы озвучки не используются. Ollama не является движком синтеза речи.

## Смысл каждого нового расчёта

Для имени, адреса, автомобиля и совместимости озвучивается контекст результата: трактовка и конкретный фокус внимания. Метод находится в отдельном раскрываемом блоке и не повторяется в каждой ячейке. Числа участников по-прежнему открывают прежние трактовки планет.

Ещё пять записей совместимости готовы: четыре смысловых варианта и метод пары/группы, 105,51 секунды. Итого за этот этап 44 новых записи, 683,34 секунды. Полный текущий каталог: 172 готовых закрытых фрагмента плюс девять прежних записей цифр. Автоматическая сверка слов не заменяет ручную проверку всех ударений.

При добавлении расчёта нужно включать его контекстную озвучку в тот же выпуск: текст из функции интерпретации, проверка покрытия всех результатов, очередь Helper/Qwen, `audit-project-narration.py --require-ready`, проверка подписанного воспроизведения, кнопка рядом с выбранным результатом. Готовый текст без готового файла не считается озвученным расчётом.

```sh

backend/.venv/bin/python scripts/prepare-relationship-narration.py
```

Тесты проверяют все 144 сочетания поддерживаемых личных чисел: звучит тот же текст, который показывает результат. Переключение пары меняет проигрыватель и останавливает предыдущую запись. Персональные имена, даты, адреса и ответы учеников не передаются в синтез. Генератор сейчас выполняется пакетно; постоянная фоновая служба не установлена.

## Источники и редактура

`packages/project-knowledge/ru.json` хранит объяснения и пути исходных материалов.
Использованы PDF «Число ДУШИ, СУДЬБЫ, УМА», исходные схемы 123W/159W,
пояснения линий в PythagoreanSquareNew и действующие серверные формулы.
В PDF ноябрь сводится до 2, приложение сохраняет 11: озвучка прямо описывает
правило текущего приложения. Формулы в рамках этой работы не менялись.

Для каждой линии объясняются её положение, смысл, сумма количества цифр
и конкретный вопрос для наблюдения за собой. В окне ячейки остаётся трактовка
её планеты без повторения общего метода. Личные числа и линии показывают
собственную арифметику пользователя отдельно от общего объяснения.

Из обучения берутся только видимые ученику поля: теория, инструкции упражнений,
вопросы и все варианты теста, задания по дням. Правильные ответы, объяснения
ключей, ответы учеников и скрытая теория не озвучиваются. Два физиологических
фрагмента адаптированы как традиционные образы; совет смотреть прямо на солнце
заменён наблюдением окружающего пейзажа. Исходная база уроков не изменялась.
Для адаптированных фрагментов доступен текст озвучки.

## Хранение и доступ

Закрытые записи и задания лежат в игнорируемой папке `backend/private/narration`,
вне статического `/uploads`. В Docker Compose эта папка сохраняется через
существующий bind mount backend; пакет объяснений подключается отдельно
только для чтения. Приватные записи исключены из контекста сборки образа. Короткая ссылка выдаётся только после входа;
при каждом воспроизведении повторно проверяются аккаунт, версия сессии,
активность и доступность урока и хеш текущего текста. Ссылка действует 30 минут,
поддерживает GET/HEAD/Range, не содержит основной токен сессии и не кешируется.
Публичный репозиторий Pages содержит только интерфейс и девять общих записей.

Хеш включает исходный текст, устную адаптацию и профиль голоса. Изменение
источника делает старую запись недоступной. Запрос на подготовку принимает
только существующий идентификатор фрагмента, без произвольного текста клиента.

## Запись и проверка

Из корня проекта:

```sh
backend/.venv/bin/python scripts/prepare-project-narration.py
/Users/brandbox/Developer/helper-voice/.venv-tts/bin/python -u scripts/generate-project-voices.py --retry-failed
backend/.venv/bin/python scripts/audit-project-narration.py --require-ready
```

`--watch` оставляет генератор ожидать новые задания; он не устанавливает
системную службу и не запускается сам после перезагрузки Mac. После правки
урока новая запись ставится в очередь кнопкой обновления озвучки.

Готовые фрагменты повторно не записываются. Проверенные короткие сегменты
сохраняются, итоговый AAC-файл публикуется атомарно. Проверяется совпадение
текста распознаванием с порогом различий 7%; ошибки не выдаются как готовые.
Цифры в распознанном тексте приводятся к сопоставимым словам; склонения числительных
и вариант написания «саттва/сатва» не считаются потерей содержания. Для распознавания
есть словарь имён и терминов курса без ключей ответов. Мантры записываются отдельно
от длинных абзацев, варианты тестов разделяются на короткие части. Метаданные
хранят услышанный текст, длительность, хеш файла и результаты каждой части.
Проверка слов не подтверждает все ударения; ручное прослушивание всех записей
не заявляется. Whisper освобождает свои веса перед следующей записью.

Итоговые проверки: 29 серверных тестов, 64 мобильных теста, TypeScript,
сборка основного сайта и экспорт web/iOS/Android прошли. Публичный API вернул
все 128 актуальных хешей со статусом ready; выборочные записи личных чисел,
диагонали и каждого урока подтвердили Range 206 и запрет кеширования.
См. `artifacts/voice-project/http-verification.json` и `published-hashes.json`.
В браузере проверено воспроизведение; установка на физические iPhone/Android
в эту проверку не входила.

## Интерфейс

В мобильной версии: кнопки в личных числах, восьми линиях, общем методе,
формуле графика и выбранной планете; отдельный аудиогид с главной.
В уроках — кнопка у каждого блока теории, упражнения и вопроса теста;
внизу — введение и задания по дням. В основном сайте — панель по разделам
урока и в окнах личных чисел/линий.

Запуск только по нажатию. Есть пауза и возврат к началу; новая запись
останавливает предыдущую, закрытие окна и переход с экрана также останавливают
воспроизведение. Прослушивание не отправляет ответы и не начисляет баллы.

Предыдущая публикация контекстных записей: `791b18b133f858020b8c7226feca9d262d31bbb1`, Pages workflow `39078543665` success. Подробности — `artifacts/voice-relationships/publication.json`.
