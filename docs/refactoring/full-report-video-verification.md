# Проверка полного разбора, Ollama и видео — 23.10.2026

## Реализованный путь

Оплаченный снимок расчётов → локальная редактура Ollama → проверка структуры и ссылок на значения → сохранённый текст → проверенная мужская озвучка → Remotion → приватный MP4. Цена пакета остаётся 666 евроцентов; повторная подготовка не создаёт платёж и не списывает баллы.

Математический снимок, формулы, шаги, исходные значения и графики не редактируются моделью. Двадцать разделов сохраняются, к ним добавляется синтез с возможными сильными сторонами, точками внимания и практиками. Оборванный или не прошедший проверку ответ не публикуется как готовый.

Общий модуль `packages/full-report/schematics.js` строит схемы для сайта, мобильного отчёта, печати и Remotion. Квадрат использует расположение 1–4–7 / 2–5–8 / 3–6–9; отдельно представлены все восемь линий и собственные взвешенные значения ведических схем. В видео фокус вводной главы сбрасывается при переходе к другому расчёту, чтобы не подсвечивать прежнее число.

Публичный API успешно проверялся после восстановления из сессии Codex; неоплаченный видеодоступ возвращал 401. Автозапуск launchd отдельно столкнулся с зависанием чтения Desktop в Python 3.12. UI подтвердил включённое состояние; на последней проверке фоновое чтение всё ещё зависало.

После этого проверен уже установленный Python 3.12.14: фоновая служба успешно прочитала файл проекта. Для NumerOM созданы игнорируемые Git окружения `backend/.service-venv` и `backend/.service-voice-venv`; исходный `.venv` сохранён. Зависимости API скопированы из существующего окружения, голосовое окружение использует уже установленные библиотеки Helper через `.pth` с `-B` (без записи bytecode в Helper). Окружения других проектов не изменялись. На новом Python прошли 87 проверок `test_report*.py` и 6 проверок service recovery; голосовые библиотеки импортированы с доступным Metal.

API, gateway, report-voice, report-video и watchdog установлены на новом runtime. API отвечает 401 без аккаунта. Проверен настоящий автоматический перезапуск gateway: после SIGTERM PID 31047 заменился PID 31471 средствами launchd. Для установки служба использует `.service-venv`, если он подготовлен; на остальных установках остаётся прежний `.venv`. При обновлении Python-зависимостей нужно также обновлять сервисное окружение и повторять проверки.

Это отдельный эксплуатационный блокер. Штатный перезапуск общего Docker был отклонён автоматической проверкой из-за влияния на другие проекты; запрос явного разрешения пользователю отправлен.
