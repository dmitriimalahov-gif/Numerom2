# Мобильная совместимость — следующий этап, 18.10.2026

Продолжение очереди «Расчёты, баллы, история» из общей спецификации. Существующий смешанный checkout сохраняется, исходники целиком не коммитятся. Публикация браузерного пилота разрешена пользователем; LIVE Stripe и реальные пользовательские баллы в проверках не используются.

- [x] Серверный модуль пары и группы: существующие формулы, проверка дат до списания, серверная цена, подтверждение цены, UUID попытки, атомарное списание вместе с результатом и журналом. Повтор UUID возвращает тот же результат; изменённые данные отклоняются.
- [x] Бесплатная история только своего аккаунта, включая сохранённый результат при задержке архива. Старые веб-маршруты используют общий модуль без изменения ожидаемых полей ответа.
- [x] Общий контракт и мобильный экран: пара/группа, 1–5 участников помимо основного, цена до действия, график, пояснения, формулы по запросу и существующие озвучки чисел.
- [x] Проверки на отдельной MongoDB: неверные даты, цена, баланс, конкуренция, повтор, отказ доставки, чужие записи. Проверки клиентского поведения, TypeScript, сборки и браузер на 320/390 px.
- [x] Обновить ограниченный шлюз, опубликовать интерфейс, подтвердить Pages и новые маршруты; записать результаты.

Решения: сохраняем текущую шкалу совместимости 1–10 и правило сохранения 11/22/33 в числе жизненного пути; не называем индекс вероятностью отношений. Общий метод показывается один раз в раскрываемом блоке. Новый мобильный интерфейс не вызывает старые незащищённые маршруты. Комментарии и интерпретации не обещают событий.

Завершено: [контракт и проверки](mobile-relationships.md), [публичная версия](public-release.md). Остальная очередь проекта сохраняется: расчёты имени/адреса/автомобиля и дополнительные инструменты, дневник/вложения/черновики, отчёты, встроенные материалы и push, подготовка устанавливаемых сборок.
