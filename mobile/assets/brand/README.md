# Иконки NumerOM

Исходник — `packages/brand/numerom-logo.svg`. PNG здесь являются ресурсами платформ; векторный логотип остаётся единственным мастер-исходником.

`icon.png`: 1024×1024, RGB без альфа-канала, светлый фон #F6F7F5. `adaptive-icon.png`: 1024×1024, прозрачный фон, знак помещён в безопасную область Android. Формат и соответствие исходному SVG проверены.

Повторный рендер: `node scripts/render-mobile-icons.cjs` из корня проекта в окружении с Sharp. Обычная сборка приложения использует готовые файлы и не требует Sharp.
