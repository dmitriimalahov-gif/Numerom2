# NumerOM для iPhone и Android

Публичный браузерный пилот: https://dmitriimalahov-gif.github.io/numerom-app/ . Условия работы сервера, проверенная версия и выпуск устанавливаемых приложений: [public-release.md](../docs/refactoring/public-release.md).

Подробный личный расчёт: семь чисел с трактовками и раскрываемыми шагами, планетарная сила, дата и имя из сохранённого результата. Последний расчёт открывается бесплатно и не меняется от редактирования профиля. Новый платный запуск отделён от просмотра; цена и баланс видны заранее. Контракт, обработка ошибок и проверки: [mobile-numbers.md](../docs/refactoring/mobile-numbers.md).

Нативный клиент на Expo SDK 57 / React Native 0.86.3 / React 19.2.3 / TypeScript. Общие аккаунты, профиль, баллы и материалы с существующим сайтом. Источник API-контрактов — действующий `backend/server.py`, не `backend_clean`.

Реализованы вход, регистрация, восстановление входа и выход, кабинет, персональные числа с ценой до действия, список уроков, теория с отметкой чтения, серверный прогресс, ответы на упражнения и комментарии преподавателя, тесты с серверной проверкой и историей, открытие прикреплённых материалов и видео, редактирование профиля, библиотека из 29 авторских PNG. Логотип — прозрачный вектор, восстановленный по логотипу NUMEROM SRL из JARVIS; общий SVG-мастер лежит в `packages/brand`, копии проверяет `scripts/sync-brand.mjs --check`. Он отображается через react-native-svg без сетевой загрузки и SVG transformers. Материалы открываются через короткоживущую ссылку в браузере или подходящем приложении устройства; встроенного видеоплеера и учёта времени просмотра нет. Bunny-видео использует новый авторизованный маршрут доступа и требует настройки защищённого embed на сервере. Оплата Stripe TEST и назначенные консультации доступны в мобильном клиенте. Совместимость пары и группы добавлена отдельным экраном с графиком, формулами, озвучками чисел и бесплатной историей; контракт описан в [mobile-relationships.md](../docs/refactoring/mobile-relationships.md). Дневник челленджа, другие расчёты (имя, адрес, автомобиль и дополнительные инструменты), отчёты и push ещё требуют переноса. Для дневника доступен переход на сайт, если задан EXPO_PUBLIC_SITE_URL. Учебные записи требуют обновлённых серверных маршрутов student_learning, просмотр файлов — student_media и HTTPS PUBLIC_API_URL; старые небезопасные маршруты скачивания не используются. Подробности: `docs/refactoring/mobile-learning.md`.

## Запуск

Из корня репозитория:

```bash
cd mobile
nvm use                     # если используется nvm; иначе нужен Node >=22.13
npm ci
cp env.example .env.local   # затем укажите свои адреса
npm start
```

Для телефона задайте доступный ему HTTPS адрес API. Для iOS Simulator без конфигурации используется `http://127.0.0.1:8000`, для Android Emulator — `http://10.0.2.2:8000`. Эти адреса не подходят физическому телефону. Переменные EXPO_PUBLIC_* включаются в приложение и не должны содержать секреты. Для release задайте `APP_VARIANT=production`; без явно заданного HTTPS API конфигурация отклоняется.

Для просмотра интерфейса в браузере: `npm run web` (порт 5130). Добавьте точный адрес предпросмотра в `CORS_ORIGINS` backend либо используйте общий reverse proxy. Это не требуется нативному приложению. Текущий backend необходимо запустить из обновлённого исходного кода, чтобы был доступен новый GET `/api/numerology/costs`. Действующий процесс автоматически не перезапускается.

Для локальных нативных сборок: `npm run ios` / `npm run android`. Нужны CocoaPods и совместимый Xcode для iOS; JDK и Android SDK для Android. Expo Go позволяет посмотреть поддерживаемые модули, но его версия должна соответствовать SDK. SecureStore используется на iOS/Android, sessionStorage — только для web preview.

## Проверки

```bash
npm test
npm run typecheck
npx expo install --check
npx expo-doctor@latest
npm run export
```

`expo export` формирует JS/Hermes и assets для iOS/Android/Web. Это **не IPA/APK** и не доказывает работу на реальном телефоне. После изменения app.config.ts или адресов запускайте export с `--clear`: Metro может сохранить прежние значения extra в кеше.

Общая проверка из корня: `bash scripts/check-platform.sh --build`. Детальный статус и ограничения — `docs/refactoring/2026-10-15-status.md`.

## Изолированная UI-проверка

`backend/tests/preview_app.py` — отдельный сервер с синтетическим профилем в памяти, без Mongo и реальных платежей. Из backend: `.venv/bin/python -m uvicorn tests.preview_app:app --host 127.0.0.1 --port 8013`. Учётные данные для него: `preview@example.invalid` / `preview-only`. Не используйте этот сервер для реальных данных.

Для тестовой web-сборки задайте `EXPO_PUBLIC_API_URL=http://127.0.0.1:8013`, export в отдельную папку `/tmp/numerom-mobile-qa` и обслуживайте её на `http://127.0.0.1:5131`. Основная сборка не использует эти фикстуры. Обычный static server не даёт SPA fallback: для перезагрузки откройте `/`, либо настройте fallback на index.html.

## Граница выпуска

На этом Mac найдены Xcode 26.6 и iOS 26.5 Simulator, но CocoaPods и Java Runtime отсутствуют. Подписанные сборки, реальные устройства, магазин приложений и production API не проверены. Идентификаторы com.numerom.app предварительные; перед публикацией подтвердите их и добавьте квадратные app icons, privacy/store metadata, реальные адреса и signing.

npm audit на 15.10.2026 сообщает 28 transitive advisories (18 high, 10 moderate; 0 critical), включая дерево Expo tooling. Предлагаемые автоматические исправления требуют смены major SDK, в том числе некорректного отката Expo; `audit fix --force` не применялся. Разбор и совместимые исправления обязательны перед выпуском, export/doctor не заменяют security review.
