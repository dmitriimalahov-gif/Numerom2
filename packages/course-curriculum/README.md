Вводное занятие имеет отдельный ID `numerom-course-intro` и порядок 0. Урок о числе проблемы имеет ID `numerom-course-0` и порядок 100. Они не заменяют друг друга. Прежние уроки 1–3 сохраняют свои ID и прогресс учеников.

## Источники и редакция

Каждый пакет содержит `sources`: относительные пути, SHA-256 и страницы; `source_refs` связывает теорию с этими источниками. `editorial_note` описывает редакторское дополнение. Исходные документы не изменены. Подробности: [4–5](notes-4-5.md), [6–8](notes-6-8.md), [0 и 9](notes-0-9.md).

Для 4 и 5 полных авторских уроков в папках запуска нет: текст создан по локальной методичке и знаниям проекта. Для остальных уроков использованы имеющиеся TXT, PDF и DOCX. Это связная учебная редакция, а не заявление о дословном переносе всех страниц и изображений архива.

Варианты формул подписаны. Составной день, мастер-число, счётчик ячейки, календарный период и произведение даты не подменяют друг друга. Практические задания — новые упражнения по темам источников. Тесты проверяют учебную методику и наблюдение, а не свойства реальных людей.

## Импорт

Из корня репозитория:

```sh
backend/.venv/bin/python scripts/import-course-curriculum.py --validate-only
backend/.venv/bin/python scripts/import-course-curriculum.py
backend/.venv/bin/python scripts/import-course-curriculum.py --apply
```

Первый режим проверяет пакет и контрольные суммы без БД. Второй только показывает план. Третий сохраняет резервную копию уроков в игнорируемой папке `backend/private/course-imports`, затем вставляет только отсутствующие документы. Требуется уникальный индекс `lessons_v2.id`, уже используемый действующей базой. Права доступа и прогресс учеников не обновляются. Повтор идентичного импорта ничего не вставляет. Отличающиеся существующие уроки блокируют запись на предварительной проверке; принудительного перезаписывания нет.

Standalone MongoDB не даёт общей транзакции на весь набор. При сбое или параллельном редактировании преподавателем часть новых уроков может успеть появиться; `plan.json` и `result.json` в резервной папке показывают состояние. Повтор после проверки продолжает вставку отсутствующих документов. Автоматического удаления уроков/ответов нет.

## Озвучка

```sh
backend/.venv/bin/python scripts/prepare-course-narration.py
/Users/brandbox/Developer/helper-voice/.venv-tts/bin/python -u scripts/run-course-narration.py
```

Подготавливаются 230 фрагментов только из видимых ученику текстов: вступление, теория, инструкции упражнений, вопросы со всеми вариантами и задания по дням. Ключи ответов и пояснения правильных вариантов не озвучиваются. Другие задания и записи проекта сохраняются.

Синтез работает локально тем же мужским голосом Helper. Сначала создаются вступления, затем остальные разделы. Каждый фрагмент проходит автоматическую сверку текста; не прошедший проверку остаётся в статусе `review`. Сверка распознавания не заменяет прослушивание ударений. Готовые аудиофайлы остаются в закрытом серверном каталоге и выдаются по короткой ссылке после проверки доступа к уроку.

Состояние длительного запуска: `backend/private/narration/course-run.json`; журнал: `course-worker.log`. Статус `all-sections` означает продолжающуюся обработку, а не готовность всех записей.
