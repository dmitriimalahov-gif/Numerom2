# Темы для личного размышления NumerOM

`ru.json` дополняет краткие планетарные трактовки девятью самостоятельными учебными карточками. Каждая карточка помогает соотнести тему с конкретным личным опытом: прочитать два абзаца, ответить на два вопроса и попробовать небольшое действие. `comparisonFocus` предлагает сопоставить темы в собственном опыте; это не сравнение людей и не показатель их совместимости.

## Происхождение

Тексты подготовлены Codex по запросу владельца NumerOM на основе материалов в проекте. Источники не редактировались. Блок `sourceSummary` — краткий пересказ только выбранной общей темы источника. `reflection`, `questions`, `practice` и `comparisonFocus` — новая литературная редакция и упражнения; их нельзя подписывать как дословные слова автора курса.

Для каждой ссылки в `sources` сохранены путь относительно корня проекта, SHA-256 исходного файла и точное место в нём. Номера страниц PDF порядковые, начиная с единицы. Пути служат для редакторской проверки; наличие пути в JSON не означает, что оригинальный файл доступен по публичному URL. Полные PDF, извлечённые страницы и персональные консультации в пакет не включены.

## Границы содержания

Область пакета — `planetary_reflection`: общие символические темы планет 1–9. Он не содержит трактовок конкретного положения числа в расчёте. Разделы правящих 10, 11 и 2, числа души, судьбы, имени, личного дня и года сюда не переносились. Совпадение цифры не делает эти контексты взаимозаменяемыми.

Из исходных страниц взяты темы для размышления. Категоричные утверждения о здоровье, поле, судьбе, способностях, «дружественности» людей и пригодности к профессиям не переносились. Карточки не определяют свойства читателя по цифре и не используются для оценки сотрудников, выбора должностей, ранжирования или автоматического состава команды.

## Формат и редактирование

- `sources`: реестр исходных файлов с `id`, `title`, `path`, `sha256`, `locator` и `kind` (`course_pdf` или `project_documentation`).
- `items`: ровно девять карточек, `digit` от 1 до 9 без повторов; `sourceIds` ссылаются только на существующие источники.
- `reflection`: массив из двух абзацев; `questions`: массив из двух разных вопросов. Остальные текстовые поля — строки.
- `theme`: краткая тема для интерфейса; `sourceSummary` отделяет происхождение от редакторского продолжения. Сведения об источнике достаточно показать один раз рядом с карточкой.
- Содержание каждой карточки — до 190 слов, включая заголовок, тему, источник, вопросы, практику и сопоставление.
- При правке сверяйте исходный фрагмент целиком и проверяйте SHA-256. Меняйте хеш только после чтения новой версии; не исправляйте несовпадение механически.
- Новая интерпретация должна приглашать вспомнить, заметить или проверить личный опыт. Избегайте формул «у вас развито», «вы подходите», «вас ждёт» и вывода личных качеств из количества цифр.
- Упражнения должны быть небольшими, конкретными и выполнимыми без покупок, раскрытия чужих данных и изменения рабочих решений.

Эта версия содержит только тексты. Существующая озвучка общей цифры не считается озвучкой новых абзацев; для новой записи нужны подготовка произношения и проверка русской речи на слух.

## Сопоставления и приложение

`comparisons.json` содержит 36 различных пар тем. Модуль `mobile/src/lib/reflectionKnowledge.js` поддерживает оба порядка выбора и отдельно повторяющуюся тему: всего 81 сочетание. Для каждой пары подготовлены вопрос и личная практика; происхождение упражнения обозначено как редакторское.

`NumberStory` открывает подробности в расшифровках и справочнике; `NumberKnowledge` содержит выбор двух тем. Личный портрет и персональный отчёт включают подробные тексты при экспорте. В портрете одинаковая тема выводится один раз. Мастер-числа и количества цифр не преобразуются модулем в обычную цифру.
