# NUMEROM brand assets

`numerom-logo.svg` — единый векторный мастер с прозрачным фоном. Геометрия окружности восстановлена, надписи переведены в контуры по логотипу компании NUMEROM SRL из JARVIS (entity 1, `brands/1/logo.jpg`). Это восстановленный SVG, не найденный оригинал дизайнера. Исходный JPG без изменений сохранён в `reference/numerom-original.jpg` только для сверки.

SVG содержит только окружности и контуры. Встроенного растра, внешних ссылок, шрифтов, скриптов и заливки фона нет. Цвет мятного знака сохраняется; на тёмных поверхностях надпись светлая. Не применять инверсию, обрезку или растяжение.

После изменения мастера: `node scripts/sync-brand.mjs`. Проверка синхронизации: `node scripts/sync-brand.mjs --check` (входит в `scripts/check-platform.sh`). Генерируемые копии сохраняются в репозитории: обычная сборка не требует генератора, трассировщика или доступа к JARVIS.

- Web: общий `Brand` в `frontend/src/components/NumeromIdentity.jsx`, автоматическая поддержка существующего класса `.dark`; `tone="light"` / `tone="dark"` для конкретной поверхности, `compact` для тесной навигации. Статика учитывает `PUBLIC_URL`.
- Mobile: `mobile/src/components/Brand.tsx`, `react-native-svg` версии, согласованной с Expo. Локальная SVG-строка, без загрузки по сети и без специальных Metro/SVGR transformers. `tone` и `compact` доступны явно.
- Favicon и PWA SVG создаются из того же мастера. Они помечены `purpose: any`, поскольку прозрачный логотип не является maskable-иконкой. Растровые store/app icons при подготовке релиза следует экспортировать из этого мастера в размерах платформ.

SVG для нативного интерфейса: https://docs.expo.dev/versions/latest/sdk/svg/
