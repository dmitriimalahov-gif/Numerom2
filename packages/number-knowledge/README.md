# База интерпретаций NumerOM: 1–9

`ru.json` — единый источник девяти авторских текстов на русском языке.
Тексты подготовлены Codex по запросу владельца: литературная подача, образ числа,
сила, тема равновесия и вопрос для размышления. Соответствия цифр и планет сверены
с `backend/domain/personal_scheme.py`. Черновик Ollama в тексты не включён после
уточнения владельца о самостоятельной подготовке материала.

Это общие значения цифр в символической системе NumerOM. Они не являются
индивидуальным расчётом. Нельзя выбирать запись по количеству повторений цифры
в ячейке: например, пустая ячейка Кету всё равно относится к цифре **7**, а не 0.
Суммы линий и мастер-числа 11, 22, 33 не сводятся к одной из записей автоматически.

`audio/ru/number-1.m4a` … `number-9.m4a` — готовые записи тем же синтетическим
мужским голосом Helper № 4. `audio-manifest.json` связывает цифру, аудио, точный
текст, длительность и SHA-256. Исходные WAV и результаты распознавания находятся
в `artifacts/voice-numbers/`; в публичную сборку они не копируются.

## Обновление

1. Отредактировать соответствующие абзацы в `ru.json`.
2. Запустить `scripts/generate-number-voices.py` через существующий Python из
   `/Users/brandbox/Developer/helper-voice/.venv-tts/bin/python`.
3. Проверить новые записи на слух. Whisper проверяет слова, но не удостоверяет
   правильность ударений. Манифесты исходников сохраняют этот статус явно.
4. Запустить тесты mobile и выполнить проверенный экспорт/публикацию.

Генератор использует локальные Qwen3-TTS/MLX и Whisper; сеть для генерации отключена.
Используется явный `lang_code="russian"`, отдельные смысловые фрагменты и паузы.
Существующие записи с совпадающими текстом и профилем повторно не генерируются.
Компактный AAC создаёт встроенный в macOS `afconvert`.

## В приложении

Раздел «Схемы» и открытая страница `/guide` содержат тексты и выбор чисел 1–9.
В расшифровке ячейки и личного числа 1–9 открывается та же история нужной цифры.
Общий метод Александрова и формулы А1–А4 показаны один раз по кнопке «Расчёт схемы»,
а не в каждой ячейке. У личных чисел остаются их индивидуальные шаги вычисления.
Для линий и мастер-чисел остаются
их собственные пояснения без подмены аудиозаписью другой цифры.
В браузере запись подгружается после нажатия «Слушать»; при смене числа или
страницы предыдущая запись останавливается. В native-экспорт включаются те же
ресурсы, воспроизведение использует [Expo Audio](https://docs.expo.dev/versions/v57.0.0/sdk/audio/).
Микрофон и фоновая запись отключены. Публикация web не является проверкой на
реальном iPhone/Android или выпуском подписанного приложения.
