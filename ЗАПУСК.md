# 🚀 Инструкция по запуску проекта NUMEROM2

## Предварительные требования
- Docker (для MongoDB)
- Python 3.12+ с виртуальным окружением
- Node.js 22+ и npm
- Git

## 📋 Пошаговый запуск

### 1. 🗄️ Запуск MongoDB (Терминал 1)
```bash
# Запустить MongoDB в Docker контейнере
docker run -d --name numerom_mongodb -p 27017:27017 -e MONGO_INITDB_DATABASE=numerom mongo:5.0

# Проверить что контейнер запущен
docker ps | grep mongo
```

### 2. 🔧 Запуск Backend API (Терминал 2)
```bash
# Из корня репозитория перейти в директорию backend
cd backend

# Активировать виртуальное окружение
source venv/bin/activate

# Запустить сервер
uvicorn server:app --host 0.0.0.0 --port 8000 --reload
```

### 3. 🎨 Запуск Frontend (Терминал 3)
```bash
# Из корня репозитория перейти в директорию frontend
cd frontend

# Установить зависимости (первый раз)
npm install

# Запустить React приложение
npm start
```

## 🌐 Адреса для доступа

- **Главное приложение**: http://localhost:3000
- **API документация**: http://localhost:8000/docs
- **Backend API**: http://localhost:8000

## 🔑 Данные для входа

### Супер Администратор
Учётные данные задаются переменными окружения (`SUPER_ADMIN_EMAIL`, `SUPER_ADMIN_PASSWORD`) при первом запуске. Явные пароли по умолчанию не предусмотрены — задайте собственные значения в `backend/.env` до первого запуска.

## 🛠️ Полезные команды

### Проверка статуса сервисов
```bash
# Проверить MongoDB
docker ps | grep mongo

# Проверить порты
netstat -tlnp | grep :8000  # backend
netstat -tlnp | grep :3000  # frontend

# Проверить процессы
ps aux | grep uvicorn       # backend
ps aux | grep "npm start"   # frontend
```

### Остановка сервисов
```bash
# Остановить backend
pkill -f uvicorn

# Остановить frontend
pkill -f "npm start"

# Остановить MongoDB
docker stop numerom_mongodb
```

### Перезапуск сервисов
```bash
# Перезапуск MongoDB
docker restart numerom_mongodb

# Backend перезапустится автоматически (--reload флаг)
# Frontend перезапустится автоматически (hot reload)
```

## 🔧 Переменные окружения

### Backend (.env в папке backend)
```env
# MongoDB настройки
MONGO_URL=mongodb://localhost:27017
MONGODB_DATABASE=numerom

# JWT настройки  
JWT_SECRET_KEY=your-super-secret-jwt-key-change-this-in-production
JWT_ALGORITHM=HS256
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=30

# Stripe настройки (замените на ваши ключи)
STRIPE_PUBLIC_KEY=pk_test_your_stripe_public_key
STRIPE_SECRET_KEY=sk_test_your_stripe_secret_key
STRIPE_WEBHOOK_SECRET=whsec_your_webhook_secret

# Настройки приложения
APP_URL=http://localhost:3000
BACKEND_URL=http://localhost:8000

# Супер админ (создается при первом запуске)
SUPER_ADMIN_EMAIL=admin@numerom.com
SUPER_ADMIN_PASSWORD=admin123
```

### Frontend (.env в папке frontend)
```env
REACT_APP_BACKEND_URL=http://localhost:8000
GENERATE_SOURCEMAP=false
```

## 🐛 Решение проблем

### Проблема с портами
```bash
# Убить процессы на портах
sudo lsof -ti:8000 | xargs kill -9
sudo lsof -ti:3000 | xargs kill -9
```

### Проблема с зависимостями
```bash
# Backend
cd backend
pip install -r requirements.txt

# Frontend
cd frontend
rm -rf node_modules package-lock.json
npm install --legacy-peer-deps
```

### Проблема с MongoDB
```bash
# Удалить и пересоздать контейнер
docker stop numerom_mongodb
docker rm numerom_mongodb
docker run -d --name numerom_mongodb -p 27017:27017 -e MONGO_INITDB_DATABASE=numerom mongo:5.0
```

## 📁 Структура проекта

```
Numerom/
├── backend/           # FastAPI сервер (разбит на routers/services/domain)
│   ├── server.py     # Точка входа приложения
│   ├── routers/      # HTTP-маршруты
│   ├── services/     # Бизнес-логика
│   ├── domain/       # Доменные модели
│   └── tests/        # unittest-тесты
├── frontend/         # React приложение (CRA/craco)
├── mobile/           # Expo / React Native приложение
├── packages/         # Общие пакеты: api-client, brand, knowledge, number-knowledge
├── scripts/          # Служебные скрипты (озвучка, экспорт)
└── docs/             # Документация
```
